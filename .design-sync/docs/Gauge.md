# Gauge

목표 진척도·수율·가동률 같은 단일 KPI 를 보여 주는 반원 게이지(d3 arc). 200×118px 고정 SVG 가 컨테이너 가운데 정렬됩니다. 트랙은 전경색 8% 회색, 값 호는 `level` 에 따라 색이 정해지고(`''` 잉크 · `ok` 초록 · `warn` 앰버 · `bad` 빨강), 가운데에 값(26px 700) + 단위(12px 캡션), 아래에 `label`(10px 캡션) 이 놓입니다. `target` 을 주면 그 위치에 앰버 눈금선을 그립니다.

`value` 가 `null`/빈 값이면 "데이터 없음" 으로 바뀝니다 — 아직 측정값이 적재되지 않은 KPI 가 실제로 이 상태로 옵니다. 값은 `min~max` 범위로 클램프되므로 계획 대비 초과(120%)를 보이려면 `max` 를 키우세요. 값은 숫자 그대로 표시되니 소수 자리는 미리 맞춰 넘깁니다.

- `value: number | null` — 표시 값. 기본 0. `null` 이면 빈 상태
- `min?: number` — 범위 하한. 기본 0
- `max?: number` — 범위 상한. 기본 100
- `unit?: string` — 값 뒤 단위(`'%'`·`'EA'`·`'대'`). 기본 `''`
- `label?: string` — 게이지 아래 설명 한 줄(예: `'종합 수율 · 목표 97.0%'`)
- `target?: number` — 목표 눈금 위치(앰버 선). 생략하면 없음
- `level?: '' | 'ok' | 'warn' | 'bad'` — 값 호 색. 기본 `''`(잉크)

```jsx
<Gauge value={97.4} unit="%" label="종합 수율 · 목표 97.0%" target={97} level="ok" />
```
