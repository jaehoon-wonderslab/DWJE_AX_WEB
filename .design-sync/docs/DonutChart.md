# DonutChart

비중을 보여 주는 d3 도넛. 왼쪽에 160px 고정 도넛(가운데 합계 19px 700 + 단위 캡션), 오른쪽에 계열 범례(9px 사각 색점 · 라벨 · 값 · 비중 %)를 가로로 놓고, 폭이 모자라면 범례가 아래로 내려갑니다(도넛 160 + 간격 14 + 범례 최소 130 = 약 304px 필요). 불량 유형 비율·목표 달성 현황(달성/진행/미달)처럼 계열 3~6개에 씁니다.

계열색은 넘어온 순서대로 테마 `series` 팔레트(잉크 #0B1440 → #1E2A78 → #3F3AA8 → 앰버 #F2C14E → 회색 #B4B8CC → 초록 #2E9E57)를 쓰므로 **큰 항목을 앞에** 두세요. 세그먼트 hover 시 값·비중 툴팁이 뜹니다(정적 화면엔 없음). 값이 `null` 인 항목은 걸러지고, 남는 것이 없거나 전부 0 이면 "데이터 없음" 문구만 놓입니다.

- `segs: { l: string; v: number | null }[]` — 계열 목록. `l` 라벨, `v` 값(건수·수량). 기본 `[]`
- `height?: number` — 도넛 SVG 높이(px). 기본 180. 도넛 폭은 160 고정
- `unitLabel?: string` — 가운데 합계 아래 단위. 기본 `'건'`

```jsx
<DonutChart
  segs={[{ l: '치수 불량', v: 412 }, { l: '도금 두께', v: 268 }, { l: '외관 스크래치', v: 154 }, { l: '기타', v: 38 }]}
  height={180}
  unitLabel="EA"
/>
```
