# Drift

전일·전주 대비 추세 글자. `Pred` 와 같은 파일의 형제로, `▲ 0.4%p` 처럼 방향 기호 + 절댓값(항상 소수 1자리) + 단위를 12px · 500 으로 그립니다. 기본은 **오르면 적색(나쁨)·내리면 성공색(좋음)** — 불량률·오판정률·비가동 시간용이고, 수율·달성률·가동률처럼 오르는 게 좋은 지표는 `invert` 로 뒤집습니다. `StatCard` 의 `sub` 옆이나 `Pred` 안, 표의 증감 열에 씁니다.

- `value: number` — 변화량. 양수는 ▲, 0 이하는 ▼
- `unit?: string` — 기본 `'%p'`. `'%'`·`'건'`·`' EA'` 등
- `invert?: boolean` — 상승을 좋음으로 해석

```jsx
<Drift value={0.4} />           // ▲ 0.4%p (적색)
<Drift value={0.3} invert />    // ▲ 0.3%p (성공색)
```
