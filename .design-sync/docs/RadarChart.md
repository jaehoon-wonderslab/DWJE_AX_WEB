# RadarChart

공정별·항목별 품질 지수(0~100 고정 범위)를 한눈에 비교하는 방사형 차트(d3 lineRadial). 컨테이너 폭을 재서 그 안에 정원으로 그리며(반지름 = min(폭, height)/2 − 42), 거미줄 4겹·축선은 헤어라인, 현재 값은 잉크 실선 + 18% 면, 목표(`t`)는 앰버 점선(`5 4`)입니다. 축 끝에 `라벨 (값%)` 이 11px 600 으로 붙고 꼭짓점엔 흰 점(잉크 테두리)이 찍힙니다. 아래 범례는 "현재 / 목표" 두 줄. 축 3~6개가 적당하고, 모든 축 `v` 가 `null` 이면 "데이터 없음" 만 놓입니다. 호버 시 축별 현재·목표 툴팁.

폭 280~320px 카드에 `height` 200~220 이 표준입니다. 값 범위를 바꾸는 prop 은 없으니 지표를 0~100 점수로 환산해 넘기세요.

> 현재 소스(RadarChart.jsx 축 라벨 루프)에 `ly` 미선언 버그가 있어 값이 있는 레이더는 렌더 시 오류가 납니다. `const ly = Math.sin(a) * (R + 18);` 복구가 필요합니다.

- `axes: { l: string; v: number | null; t?: number | null }[]` — 축 목록. `l` 축 이름, `v` 현재 값(0~100), `t` 목표(생략하면 점선 없음). 기본 `[]`
- `height?: number` — SVG 높이(px). 기본 210

```jsx
<RadarChart
  axes={[{ l: '수율', v: 97, t: 97 }, { l: '가동률', v: 88, t: 92 }, { l: '납기', v: 94, t: 95 }, { l: 'AOI 정확도', v: 91, t: 90 }, { l: '재검률', v: 76, t: 85 }]}
  height={220}
/>
```
