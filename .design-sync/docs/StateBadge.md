# StateBadge

한국어 상태 문자열 하나로 색을 자동으로 고르는 배지. `Badge` 의 형제(같은 파일)로, 설비·LOT·판정·결재 상태처럼 값이 곧 상태인 곳에서 `tone` 을 일일이 고르지 않으려고 씁니다. 매핑은 소스의 `STATE_TONE` 사전을 따릅니다 — `가동`·`정상`·`양품`·`완료`·`성공`·`사용`·`서비스 중` → green, `경고`·`주의`·`경계`·`보류` → amber, `진행 중`·`실행중`·`검토중` → blue, `비가동`·`정지`·`불량`·`위험`·`실패`·`점검필요`·`반려` → red, `대기`·`점검 중`·`보관` 과 사전에 없는 문자열 → 기본 회색.

배지 규칙은 Badge 와 같습니다(10.5~11px · 600 · 캡슐 · 아이콘 없음). 목록 줄에서는 이름 오른쪽 끝에 하나만 두고, 새 상태 문구가 생기면 사전에 추가하되 앰버는 주의에만 씁니다.

- `state: string` — 상태 문구(그대로 표시되며 색 판정의 키)
- `style?: ViewStyle` — 바깥 캡슐 스타일 덧씌움

```jsx
<StateBadge state="비가동" />
```
