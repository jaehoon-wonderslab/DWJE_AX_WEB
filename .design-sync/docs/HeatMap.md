# HeatMap

설비(행) × 시간대·요일(열) 가동률 격자. 왼쪽 120px 라벨 열(11.5px 600, 오른쪽 정렬) 뒤에 셀(최소 42px 폭, `cellHeight` 높이, 4px 반지름, 4px 간격) 이 가로로 늘어나며, 각 셀 안에 값이 11px 600 tabular 숫자로 찍힙니다. **값이 낮을수록 진하게** 칠해 문제 구간(최저 가동률)이 바로 보이게 하는 방향이므로 불량률처럼 높을수록 나쁜 지표에는 맞지 않습니다. 값이 없는 칸은 회색 바탕에 "—". 아래에 `hi → lo` 5단계 범례 막대가 붙습니다. 격자가 500px 보다 좁은 자리에서는 가로 스크롤(스크롤바 숨김)이 됩니다 — 카드 폭 520px 이상을 권장합니다.

색은 현재 소스에 파랑 5단계(#E5F0FD → #4385E0)가 하드코딩되어 있어 테마 `series` 팔레트를 따르지 않습니다(디자인 반영 시 잉크→앰버 5단계로 맞출 것). `invert` prop 은 받기만 하고 아직 동작하지 않습니다.

- `rows: string[]` — 행 라벨(설비명). 비면 "데이터 없음"
- `cols: string[]` — 열 라벨(`'06'`·`'08'`… 또는 요일). 비면 "데이터 없음"
- `data: (number | null)[][]` — `data[행][열]` 값. 빠진 칸·`null` 은 "—"
- `unit?: string` — 범례 양끝 단위. 기본 `'%'`
- `lo?: number` — 가장 진한 색이 되는 값. 기본 40
- `hi?: number` — 가장 연한 색이 되는 값. 기본 100
- `invert?: boolean` — 예약(미구현). 기본 true
- `cellHeight?: number` — 셀 높이(px). 기본 32

```jsx
<HeatMap
  rows={['프레스 1 (PR-01)', '프레스 2 (PR-02)', '프레스 3 (PR-03)']}
  cols={['06', '08', '10', '12', '14', '16', '18', '20']}
  data={[[96, 98, 97, 88, 95, 97, 96, 94], [92, 94, 91, 85, 90, 93, 89, 91], [78, 64, 52, 47, 58, 71, 83, 86]]}
  lo={40} hi={100} unit="%"
/>
```
