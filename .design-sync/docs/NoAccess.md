# NoAccess

메뉴 접근 권한이 없는 부서가 화면에 들어왔을 때 본문 전체를 대신하는 안내. 아이브로 "Access denied"(11px 600 회색) · 21px 600 잉크 제목 "접근 권한이 없는 화면입니다" · 12px 캡션 회색 안내 문장(최대 폭 460) · 40px 헤어라인, 모두 가운데 정렬이고 세로 여백 72 입니다. 페이지 머리말(`PageHead`) 아래 본문 자리에 그대로 두며 버튼은 없습니다 — 권한 지정은 시스템관리 화면에서 합니다.

- `dept?: string` — 부서명. 주면 "○○ 에 허용되지 않은 화면입니다." 가 문장 앞에 붙습니다
- `style?: any`

```jsx
<NoAccess dept="생산1팀" />
```
