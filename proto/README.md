# Claude Design 전달용 단일 HTML

전달할 파일은 **index.html 하나**입니다. CSS, JavaScript, React 화면, 차트, 글꼴, 더미 데이터가 모두 파일 안에 들어 있습니다.

## 사용

1. index.html을 브라우저에서 더블클릭해 엽니다.
2. 관리자 샘플 계정 입력을 누른 후 로그인합니다.
3. 같은 index.html을 Claude Design에 첨부하고 후속 편집을 요청합니다.

샘플 계정은 admin / Demo!2026입니다. 입력값은 파일 안의 스크립트로 검사합니다. API, DB, 웹 서버, npm 설치, 별도 자산 파일이 필요 없습니다. 글꼴·라이브러리도 외부에서 받지 않습니다. 변경 데이터는 메모리에서 처리되며 새로고침 시 초기화됩니다.

## 화면

현재 앱의 로그인·성좌 애니메이션·자연어 질의·대시보드·생산 및 품질 관리·보고서·시스템관리 화면을 재사용합니다. 파일 내 해시(#/menu/report 등)로 이동합니다. 실제 AI 추론과 서버 전용 파일 생성은 연결하지 않습니다.

## 참고 파일

- CLAUDE_DESIGN_BRIEF.md: 첨부 시 함께 사용할 설명.
- source/: 재편집·재빌드용 소스. 전달에 필요하지 않습니다.
- build-standalone.cjs: 개발용 단일 HTML 생성기.
- verify-standalone.cjs: 파일 직접 열기 검증 스크립트.
- archived-web/: 앞서 생성했던 서버 실행형 산출물과 이전 버전. 현재 HTML의 의존성이 아닙니다.

검증: file:// 직접 실행, 샘플 인증 성공·실패, 삼각형 애니메이션, 보고서 메뉴 클릭, 31개 업무 화면 탐색. 런타임 화면 오류 0건, 외부 자산·API 요청 0건.
