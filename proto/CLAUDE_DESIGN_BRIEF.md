# Claude Design에 index.html과 함께 전달할 설명

첨부한 index.html은 덕우전자 AX의 독립 실행 프로토타입입니다. 화면 코드, 스타일, 글꼴, 라이브러리, 더미 데이터가 모두 HTML 내부에 들어 있습니다. 서버나 별도 파일 없이 브라우저로 직접 열 수 있습니다.

이 파일을 기반으로 후속 UI/UX 편집을 진행해 주세요. 기존 화면의 레이아웃, 메뉴, 반응형 동작, 삼각형 성좌 애니메이션을 보존하고 요청한 부분을 수정해 주세요.

로그인은 admin / Demo!2026을 스크립트로 검사합니다. 관리자 샘플 계정 입력 버튼이 있습니다. 모든 업무 데이터는 파일 안의 상수와 로컬 함수에서 가져옵니다. API·DB·외부 AI·외부 자산 의존성을 추가하지 마세요. 결과물 역시 단일 HTML로 유지해 주세요.

화면 범위는 자연어 질의, 대시보드 3개, 생산 및 품질 관리 3개, 보고서 7개, 시스템관리 15개, 알림, 이전 보고서입니다. 보고서는 드롭다운과 자주 쓰는 보고서 버튼을 사용합니다. 업무 화면에서 AI 질의 패널을 열 수 있습니다.

HTML의 스크립트는 수정 위치를 찾기 쉽게 압축하지 않았습니다. 모듈 경로 주석과 AI_SUMMARY, prototypeMock, commonMock, LoginView, ConstellationField, Sidebar, ReportPicker 등의 이름을 검색하면 관련 코드·샘플 데이터를 찾을 수 있습니다. URL 해시로 화면을 전환합니다.

색상은 #f4f5f7 캔버스, 흰 패널, #0B1440 잉크, #F2C14E 데이터 강조이며 Pretendard/Inter 글꼴이 내장되어 있습니다.
