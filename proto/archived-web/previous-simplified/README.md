# 덕우전자 AX 정적 프로토타입

Claude Design 서비스에 컨셉과 화면 흐름을 전달하기 위한 독립형 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저로 직접 열면 됩니다. 별도 빌드 도구나 서버가 필요하지 않습니다.

## 데모 로그인

- 관리자 버튼: **관리자 더미 계정으로 바로 시작**
- 아이디: `admin`
- 비밀번호: `admin1234`

로그인 이후 AI 질의 홈, 생산 모니터링, 생산 및 품질 관리, 보고서, 시스템 관리 화면을 탐색할 수 있습니다.

## 데이터 정책

`app.js`의 `DEMO` 상수만 사용합니다. `fetch`, `axios`, API endpoint, DB 연결은 포함하지 않았습니다. 화면의 버튼과 질의는 사용 흐름을 보여주기 위한 더미 인터랙션입니다.

## 구성

- `index.html` — 진입점
- `styles.css` — 라이트 워크스페이스 UI와 반응형 스타일
- `app.js` — 로그인, 라우팅, 더미 데이터, 인터랙션
- `CLAUDE_DESIGN_BRIEF.md` — Claude Design 입력용 제품·화면·컴포넌트 명세
