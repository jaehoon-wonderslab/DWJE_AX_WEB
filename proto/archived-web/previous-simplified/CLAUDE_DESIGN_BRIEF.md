# 덕우전자 AX 웹 프로토타입 기획서

## 1. 서비스 한 줄 정의

생산·품질 현장의 데이터를 한곳에 모아, 관리자가 자연어로 상황을 묻고 다음 액션까지 빠르게 결정하도록 돕는 AI 의사결정 지원 워크스페이스.

## 2. Claude Design 입력용 프롬프트

덕우전자 제조 현장을 위한 데스크톱 우선 웹 업무 도구를 디자인해 주세요. 서비스명은 “덕우전자 AX”이고 부제는 “decision workspace”입니다. 핵심 사용자는 생산 관리자, 품질 관리자, 시스템 관리자입니다.

전체 방향은 차분하고 신뢰감 있는 라이트 워크스페이스입니다. 캔버스는 `#f4f5f7`, 콘텐츠 패널은 흰색, 20~24px 둥근 모서리, 아주 옅은 테두리와 그림자를 사용합니다. 주요 색상은 잉크 네이비 `#0B1440`, 보조 회색 `#73798B`, 앰버 `#F2C14E`, 상태 초록 `#16956F`, 위험 빨강 `#D94B61`, 차트 블루 `#5574D8`입니다. 한글은 Noto Sans KR 또는 Pretendard, 숫자와 영문은 Inter를 사용하세요. 제목과 KPI는 굵기 600~700, 자간은 약간 좁게 설정합니다.

왼쪽에는 고정 사이드바를 배치합니다. 상단에는 작은 사각형 D 로고와 “덕우전자 AX”를 보여주고, 메뉴는 “AI 질의 홈”, “생산 모니터링”, “생산 및 품질 관리”, “보고서”, “시스템 관리” 순서입니다. 활성 메뉴는 밝은 회색-블루 배경과 앰버 점으로 표시합니다. 오른쪽 상단에는 알림 아이콘, 미확인 알림 3개 배지, 관리자 프로필, 로그아웃을 배치합니다.

첫 화면은 AI 질의 홈입니다. “오늘의 업무를 물어보세요.”라는 큰 제목, “관리자님, 좋은 아침입니다.”라는 인사말, 종합 수율 98.2%, 생산량 12,480 EA, 현재 이슈 3건의 요약을 보여주세요. 아래에 “예: 오늘 불량률이 높은 공정과 원인을 알려줘” 플레이스홀더가 있는 자연어 질의 입력창과 “질의하기” 버튼을 배치합니다. 질의 후에는 더미 AI 답변 영역이 펼쳐지고, 프레스 3호기 진동 수치 상승과 AOI 2라인 납땜 부족 불량을 원인 후보로 제안합니다.

생산 모니터링 화면에는 KPI 4개(오늘 생산량, 종합 수율, 불량 건수, 가동 설비), 시간대별 생산 실적 막대 차트, 현재 알림 테이블을 배치합니다. 생산 및 품질 관리 화면에는 실적 집계·조회, 불량 현황 조회, AOI 판정 분석·예측의 3개 진입 카드를 배치하고, 라인별 품질 현황 표와 AI 추천 액션 카드를 함께 보여주세요. 보고서 화면에는 실적, 불량, AOI, 일일 생산현황, 출하 계획, 스크랩 보고서의 6개 선택 카드를 배치합니다. 시스템 관리 화면에는 사용자 관리 표와 “프로토타입 상태” 카드를 배치합니다.

## 3. 로그인 화면

로그인은 중앙의 흰 패널을 사용한 2열 구조입니다. 왼쪽 네이비 영역에는 “데이터를 넘어, 판단을 빠르게.” 카피와 앰버 포인트 장식을 배치하고, 오른쪽에는 사번 입력, 비밀번호 입력, 네이비 “로그인” 버튼을 배치합니다. 로그인 버튼 아래에 반드시 “▣ 관리자 더미 계정으로 바로 시작”이라는 점선 보조 버튼을 추가하세요. 이 버튼을 누르면 별도 인증 없이 관리자 워크스페이스로 진입합니다.

## 4. 더미 계정 및 데이터

프로토타입 계정은 `admin / admin1234`입니다. API나 DB를 호출하지 말고 프런트엔드 상수로만 동작하게 하세요. 샘플 기준일은 2026-09-09입니다. 모든 표·차트·알림·AI 답변은 샘플 데이터입니다. 버튼은 화면 전환, 토스트, 답변 펼침 등 프로토타입 확인에 필요한 최소 동작만 제공합니다.

## 5. 화면 목록 및 성공 기준

1. 로그인: 관리자 더미 계정 버튼으로 한 번에 입장 가능
2. AI 질의 홈: 요약 KPI, 질문 입력, 더미 응답 확인 가능
3. 생산 모니터링: KPI, 차트, 알림을 한 화면에서 확인 가능
4. 생산 및 품질 관리: 3개 업무 진입점과 품질 표 제공
5. 보고서: 6개 보고서 선택 카드와 프로토타입 안내 제공
6. 시스템 관리: 사용자 목록과 API/DB 미연결 상태 표시
7. 모든 화면: 좌측 메뉴로 이동 가능하고, 로그아웃으로 로그인 화면 복귀

## 6. 구현 제약

- 백엔드, API, DB, 외부 인증을 연결하지 않습니다.
- 정적 프로토타입으로 실행할 수 있어야 합니다.
- 모바일 폭에서는 사이드바를 숨기고 콘텐츠를 1열로 재배치합니다.
- 실제 제품 구현 시 API 연결부, 권한별 라우팅, Tabulator 기반 표, D3 기반 차트로 교체할 수 있도록 컴포넌트 경계를 유지합니다.
