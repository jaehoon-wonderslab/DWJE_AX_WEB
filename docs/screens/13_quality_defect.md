# /quality/defect — 불량 현황 조회

시작일·종료일로 조회합니다. 기본 기간은 로컬 오늘 7일 전부터 오늘까지입니다.
품질보증팀·생산관리팀·제조팀·경영진·통합관리자가 접근하며 수량/불량률 권한을 따릅니다.

## 카드

- 불량별 비중: 파레토 차트와 유형별 표. 원장 불량 수량 기준 비중이며 유형 미상을 포함합니다.
- 불량 유형별 분포(상세): 기존 유형 분포와 제품 카드 사이에 배치. 불량 유형 → 제품 → 라인(설비) → 공정 트리와 선버스트. 제품 API를 재사용하며 유형 행은 전체 제품 원장 수량을 분모로 사용합니다.
- 제품별 불량 현황: 제품 → 불량 유형 → 라인(설비) → 공정 트리와 확대 가능한 선버스트.
- 라인별 불량률: 라인(설비) → 공정 → 제품 → 불량 유형 트리와 확대 가능한 선버스트.

표는 생산 실적 화면과 같은 Tabulator 스타일, 내용에 맞춘 열 너비, 수동 조절, 머리글 검색,
페이지 이동과 상단 가로 스크롤을 제공합니다. 제품 표에는 제품 코드·제품명·유형·라인 코드·설비명·공장·공정·수량·불량 수량·불량률·비중을 나눠 표시합니다.
라인과 설비는 현재 API에서 같은 대상이며 코드는 라인(설비) 코드, 이름은 설비명으로 표시합니다.

## 제품별 계산 기준

| 단계 | 수량(totalQty) | 불량률(defectRate) | 비중(ratio) |
| --- | --- | --- | --- |
| 제품 | 제품 원장 정상+불량 수량 | 제품 불량 ÷ 제품 수량 × 100 | 전체 불량 대비 |
| 불량 유형 | 해당 제품 원장 수량 | 유형 불량 ÷ 제품 수량 × 100 | 제품 불량 대비 |
| 라인(설비) | 해당 제품·설비 원장 수량 | 유형·설비 불량 ÷ 제품·설비 수량 × 100 | 유형 불량 대비 |
| 공정 | 해당 제품·설비·공정 원장 수량 | 해당 불량 ÷ 해당 원장 수량 × 100 | 상위 설비 불량 대비 |

유형부터 수량은 반복되는 분모이므로 형제 행끼리 합산하지 않습니다.
불량 수량은 유형 미상을 포함해 상위·하위 합을 보존합니다. null은 0으로 바꾸지 않고 —로 표시합니다.

## 선버스트

[확대 가능한 선버스트 참고](https://observablehq.com/@d3/zoomable-sunburst).
공통 컴포넌트는 src/shared/components/charts-d3/ZoomableSunburst.jsx 입니다.

- 면적 기준은 불량 수량입니다. 불량률은 선택 상세에 별도로 표시합니다.
- 최대 두 겹을 표시하고 조각/검색 목록을 누르면 하위 구성을 확대합니다.
- 중앙 원 또는 상위로 버튼으로 돌아가며, 전체 보기로 초기화합니다.
- 작은 조각은 검색·페이지 목록으로 접근합니다. 상위 N개로 자르지 않습니다.
- 조각의 호 길이에 맞춰 이름과 수량을 표시하며, 긴 이름은 줄임표를 사용합니다. 전체 이름은 단계명 포함 경로·목록·선택 상세에서 확인합니다. 짙은 팔레트와 흰 라벨을 사용하며 확대 전후 노드 색을 유지합니다.
- 중앙에는 선택 단계·항목명·수량을 표시합니다. 경로 버튼으로 원하는 상위 단계에 이동하며 검색은 제품·불량·라인·공정 문맥을 포함합니다.
- 반응형 배치로 가로 스크롤 없이 표시합니다. 수량 권한이 없으면 차트를 표시하지 않습니다.
- 조회 데이터가 바뀌면 확대 위치와 검색을 초기화합니다.

## 선버스트 툴팁·대분류 경계

고정 상세 카드를 제거하고 차트 조각·목록의 마우스 오버 또는 키보드 포커스에 툴팁을 표시합니다. 툴팁은 화면 가장자리 안에 배치되며 마우스 이탈·스크롤·Escape·확대 이동 시 닫힙니다. 대분류 외곽선은 하위 고리까지 이어집니다. 전체 대비 비율은 확대 전 전체 불량 수량을 분모로 유지하고, 선택 그룹 내 비율을 별도로 표시합니다.

검증: WEB_URL=http://localhost:8092 node tests/quality/sunburst-tooltip-browser.cjs

툴팁 상세는 항목명/값 2열 표로 표시합니다. 전체 대비와 그룹 내 비율은 별도 행이며, 그룹 내 비율은 조각의 바로 상위 노드 불량 수량을 분모로 합니다(현재 확대 화면 전체와 구분). 그룹 기준 행에 상위 이름을 표시합니다. 최상위 항목은 상위가 전체이므로 두 비율이 같습니다.

선버스트 조각·목록을 가리키거나 키보드로 포커스하면 대응 영역과 상하위 경로를 강조하고, 나머지 영역은 흐리게 표시합니다. 굵은 외곽선·위치 표시점과 중앙 항목명·수량이 함께 바뀝니다. 마우스 이탈·Escape·확대 이동 시 초기 상태로 돌아갑니다.

트리 구분은 펼침 버튼과 1~4단계 열로 나눕니다. 상위 단계명은 흐리게 유지하고 현재 단계는 진한 글자·배경·왼쪽 경계선으로 강조합니다. 펼침 버튼은 닫힌 상태 +, 열린 상태 −이며 aria-expanded를 제공합니다. 마지막 단계에는 버튼을 표시하지 않습니다.

검증: WEB_URL=http://localhost:8092 node tests/quality/tree-stages-browser.cjs

계층 표시를 132px 단일 열로 압축했습니다. 1~4 단계 번호와 +/−, 14px 들여쓰기·수직 연결선으로 깊이를 표시합니다. 단계 의미는 카드별 범례와 번호 툴팁으로 제공합니다. 기존 단계별 분리 열은 제거했습니다.

계층 열의 단계 번호는 제거했습니다. +/− 버튼의 툴팁과 접근성 이름에 상위부터 현재 계층까지의 의미와 펼침/접힘 동작을 제공합니다. 범례도 번호 없이 계층명으로 표시합니다.

트리 표는 자식 행이 페이지 제한으로 잘리지 않도록 페이지 나누기 대신 높이 560px의 내부 세로 스크롤을 제공합니다. 펼친 행과 전체 최상위 항목을 같은 스크롤 영역에서 조회하며 가로 스크롤도 유지합니다. 비트리 표의 페이지 나누기는 기존대로입니다.

세 번째 단계 아래 마지막 상세가 한 개이며 불량 수량이 같으면, 하위 차원(공장·공정·유형 등)을 해당 행에 합쳐 펼침 버튼을 생략합니다. 수량과 비중은 세 번째 단계의 기준을 유지합니다. 상세가 두 개 이상이면 기존 하위 행을 유지합니다. 품질 화면의 유형·제품·라인 트리 표에 공통 적용하며, 원본 API와 차트 계층은 유지합니다.

검색은 각 열의 하위 데이터까지 검사하고 일치하는 경로를 자동으로 펼칩니다. 검색 해제 시 이전 펼침 상태로 돌아갑니다. 붙여넣기·한글 조합 완료도 검색에 반영합니다. 단일 경로 합치기는 최상위 분류를 제외한 2단계부터 연속 적용하며 분기가 둘 이상이면 유지합니다.

검색은 필터만 적용하며 트리를 자동으로 펼치거나 접지 않습니다. 사용자가 +/− 버튼으로 직접 펼침 상태를 조작합니다.
