# 공정 및 제품 대시보드 — 기간별 생산·품질 확인

2026-09-07 개편. 적용 범위는 `/dashboard/process` 페이지와 이 페이지 전용 모델·컨트롤러다.

## 화면 기획

관리자는 기간의 생산·불량 규모와 점검 우선순위를, 현장 작업자는 확인할 제품·공정을 바로 찾을 수 있도록 다음 순서로 배치한다.

1. **조회 조건**: 실적 집계·조회의 집계 단위, 시작일, 종료일, 제품 검색·다중 선택, 조회 버튼. 공정 선택도 제공한다.
2. **생산 현황**: 투입·양품·불량·수율 네 지표. 현재 조회 기간과 대상을 바로 위에 표시한다.
3. **먼저 확인할 항목**: 불량 수량 최다 제품과 전체 불량 내 비중, 불량률 최고 공정과 투입량, 수량 미집계 제품 수. 제품 상세 이동·공정 조회·미집계 제품 필터로 연결한다.
4. **D3.js 차트**: 기간별 투입량·불량률 추이, 불량 상위 8개 제품, 불량률 상위 8개 공정.
5. **Tabulator 표**: 전체 공정 비교와 제품별 상세. 정렬·검색, 불량 발생/집계 확인 필터, 엑셀 다운로드를 제공한다.

이슈는 실제 집계 수량·비율의 상대적 순위다. 설비 고장, 불량 원인, 목표 미달 같은 근거 없는 진단은 하지 않는다. 전체 공정 비교에는 선택 공정과 무관하게 같은 기간·제품의 모든 공정을 포함한다.

## 조회 동작

- 최초: 마지막 실적일 기준 최근 7일, 전체 제품·공정.
- 일별 최근 7일, 주별 최근 4주, 월별 최근 3개월. 단위 변경 시 즉시 조회한다.
- 날짜·제품·공정 수정은 조회 버튼으로 적용한다. 입력 중인 조건과 적용된 조건을 구분한다.
- 주별은 월요일, 월별은 월초가 기준이다. 첫·마지막 구간은 선택한 날짜 범위만 집계한다.
- 날짜 유효성·순서와 최대 92일 간격을 검증한다.
- 이슈 카드의 ‘이 공정 조회’는 현재 **적용된** 기간·제품을 유지하며 공정만 변경한다.
- 로딩·실패·새 조건 적용 중에는 이전 결과를 새 결과처럼 표시하지 않는다.

## 값이 없는 경우의 표현

| 상황 | 화면 문구 |
| --- | --- |
| 수량을 아직 집계할 수 없음 | 수량 미집계 |
| 투입량이 0이라 수율·불량률을 산출할 수 없음 | 생산 실적 없음 |
| 수율·불량률 산출에 필요한 수량이 부족함 | 산출 자료 부족 |
| 해당 지표의 조회 권한이 없음 | 조회 권한 없음 |
| 제품명 또는 공정명이 없음 | 제품명 미등록 / 공정명 미등록 |
| 조회 결과 자체가 비어 있음 | 기간·대상을 바꾸도록 안내 |

미집계 수량은 0으로 바꾸지 않는다. 숫자가 없을 때 EA/% 단위를 붙이지 않으며, 엑셀에도 동일한 문구를 사용한다. 차트는 자료가 부족한 구간을 그리지 않고 이유를 안내한다.

## 데이터 연동

기존 구현된 `GET /api/v1/dashboard/process/period`를 사용한다.

요청: `from`, `to`, `unit=day|week|month`, 선택적 `processId`, `productCodes[]`.
응답: `summary`, `periods[]`, `products[]`, `processes[]`.

전체 요약에는 제품 미매핑 실적도 포함된다. 제품 상세의 미집계 수량으로 합계가 달라질 수도 있으므로 제품별 수량을 더해 전체 합계를 만들지 않는다. 비율은 서버가 실제 합계 수량으로 계산한 값을 사용한다.

API 검증 근거: `../API/docs/PROCESS_PERIOD_API_FEEDBACK_20260907.md` (API 디렉터리 기준).

## 검증 명령

- `node tests/dashboard/process-model.cjs`: 미집계·권한·0의 구분, 날짜 경계, 이슈 순위.
- `node tests/dashboard/process-browser.cjs`: 미집계 표시, 이슈 상세 이동, 제품 필터, 공정 조회, 날짜 오류, 주별 조회, 엑셀, 모바일, 오류 화면.
- `node tests/dashboard/process-live.cjs`: 관리자 실 API 조회, 일/주/월 구간 수, 제품·공정 필터, 공정 비교 유지, 무실적 문구.
- `npm run check`, `npm run build:web`.
