# 00. 공통 — 레이아웃 · 컴포넌트 · 규약

> 모든 URL 문서의 전제입니다. 화면별 문서에는 이 문서에 적힌 공통 요소를 다시 적지 않습니다.

- 프레임워크 : React Native for Web (Expo SDK 57) + **Expo Router 파일 기반 라우팅**
- 계층 : **MVC** — `src/domains/<도메인>/{model,controller,view}`
- 라우트 파일 : `app/(auth)/*`, `app/(main)/**` — **메뉴 1개 = 라우트 1개 = 파일 1개**
- 화면 ID ↔ URL 매핑 : `src/shared/constants/menu.js` + `src/shared/navigation/routes.js`
- API 카탈로그 : `src/services/api/endpoints.js` — **255건** (명세 236 + 인증·공통 확장 19)

### 1-2. 인증 그룹 (`app/(auth)/_layout.jsx`)

- 사이드바·상단바 **없음**. `AuthCard` 만 중앙 정렬.
- 이미 로그인 상태면 `next` 파라미터 → 없으면 `HOME_PATH(/dashboard/ai)` 로 리다이렉트.
- `IS_DEMO_AUTH`(`EXPO_PUBLIC_LIVE_AUTH=false`) 면 인증 화면 자체를 건너뜀.

### 1-3. 업무 그룹 (`app/(main)/_layout.jsx`) — 3분할

```
┌──────────┬───────────────────────────────────────────┐
│ Sidebar  │ Topbar                                    │
│ (240px)  ├───────────────────────────────────────────┤
│ 메뉴 트리 │ <Slot /> = 각 화면 (PageContainer 내부)     │
└──────────┴───────────────────────────────────────────┘
```

진입 시 순서대로 3가지를 확인합니다.

1. **로그인 여부** — 비로그인이면 `/login?next=<가려던 경로>` 로 이동
2. **실적 보유 기간** (`useDataRangeBootstrap` → `GET /api/v1/common/data-range`) — 화면 기본 기준일 산출용, 본문보다 먼저 로드
3. **메뉴 접근 권한** (`can(screenId)`) — 없으면 토스트 후 `dash-ai` 로 되돌림, 렌더는 `NoAccess`

- 반응형 : 창 너비 **860px 이하**면 사이드바 자동 숨김

## 3. 공통 규약

### 3-1. 권한 2종

| 구분 | 단위 | 판정 | 위반 시 |
| :--- | :--- | :--- | :--- |
| **메뉴 접근 권한** | 부서 × 화면 ID | `useAuthStore.can(screenId)` | 사이드바 비노출 + URL 직접 진입 차단 |
| **데이터 접근 권한** | 부서 × 데이터 항목 7종 | `useAuthStore.canData(fieldKey)` | 값 자리에 `비공개` (화면·인쇄·CSV 전 구간) |

데이터 항목 7종 : `qty`(생산·출하 수량) · `yield`(수율·불량률) · `price`(단가·금액) · `customer`(고객사·거래처) · `plan`(출하 계획) · `mold`(금형·설비 상세) · `worker`(작업자 정보)

부서 6종 : 품질보증팀(QA) · 생산관리팀(PC) · 제조팀(MF) · 전산팀(IT) · 경영진(EX) · 통합관리자(MA, 전 권한)

### 3-2. 페이징

- 훅 `usePaging({ size = 50, resetKey })` → `params{page,size}` / `bind{page,size,onPage,onSize}`
- 기본 선택지 `PAGE_SIZES = [25, 50, 100, 200]`, **`size = 0` 은 「전체」** (서버 규약)
- `resetKey`(조회 조건 문자열)가 바뀌면 자동으로 1쪽 복귀
- 내려받기·인쇄는 **화면의 쪽과 무관하게 전량**을 다시 조회해서 처리

### 3-3. 조회 · 상태 로딩

- 훅 `useAsync(fn, deps, { skip, silent, initialData })`
- 조회 조건(SelectField·DateField)의 **선택지는 서버 기준정보에서 받습니다.** 화면에 하드코딩하면 서버 코드와 달라 0건이 됩니다.
- 실시간 폴링 : 생산 모니터링 10초 / Agent 실행 현황 30초 / 데이터 연동 이력 30초(진행 중 작업이 있을 때만)

### 3-4. 내려받기 · 인쇄

- `shared/utils/exportUtil` — `downloadXls({name,head,rows})` · `downloadCsv(...)` · `printDocument({nodeId,title,role})`
- 보고서 화면은 `ReportDoc nodeId` 를 잡아 두고 그 노드만 인쇄
- 모든 내려받기·인쇄는 **보고서 다운로드 이력(SY-14)** 에 자동 기록 (`POST /api/v1/download-logs`)

### 3-5. 자동 감사 기록

권한 변경 · 마스킹/해제 요청 · 원본 조회 · 보고서 출력 · 모델 전환 · 단가 수기 조정 → **보안 감사 로그(SY-09)** 자동 기록

### 3-6. 전역 스토어 (Zustand)

| 스토어 | 보관 값 |
| :--- | :--- |
| `useAuthStore` | `userInfo` · `tokens` · `menuPerms` · `dataPerms` · `servingModelVer` · `can()` · `canData()` |
| `useAppStore` | `baseDate` · `dashProcess` · `dashModels` · `dashTopN` · `recentModels` + 날짜 헬퍼(`lastDataDate`,`recentRange`,`currentMonthRange`,`recentDays`,`yearOptions`,`yearMonthOptions`) |
| `useUiStore` | `toast()` · `openModal()` · `openDrawer()` · `sidebarCollapsed` |
| `useThemeStore` | `mode` · `toggleTheme()` |

## 5. 공통 개발 체크리스트

- [ ] 루트 레이아웃 — 세션 복원 · 테마 · 오버레이 3종

- [ ] `Pagination` + `usePaging` 목록 화면 전체 적용
