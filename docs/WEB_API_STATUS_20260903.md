## 9. 인수인계 메모

**API 를 고칠 때** — 요청 형식은 `① 화면·동작 ② 엔드포인트와 파라미터 전체 ③ 기대/실제 ④ 재현 절차`.
API 세션(`001-4e`)이 이 형식을 쓰면 빠르다고 했고, 실제로 그랬습니다.

**오늘 가장 자주 나온 버그 유형** — 참고하시면 같은 자리를 덜 밟습니다.

1. **200 인데 아무 일도 안 일어남** — 화면이 서버가 모르는 키를 보내고 서버가 조용히 무시.
   계정 상태 토글 · 지표 수치 편집 · 발송 조건 등록 · 수동 이관 3곳에서 반복.
   → `FAIL_ON_UNKNOWN_PROPERTIES` 활성화로 이제 400 으로 드러납니다.
2. **선택지 하드코딩** — 화면에 `'생산'`, 서버는 `PROD`. 무엇을 골라도 0건.
   → `09-filters.spec.js` 가 잡습니다.
3. **응답에 없는 필드로 열 그리기** — 빈 칸 또는 `NaN` 표시.
   → `11-columns.spec.js` 가 잡습니다(자료 0건인 표는 카탈로그 선언으로 대조).
4. **한 조회가 느려 화면 전체가 멈춤** — `unwrapAll` 로 묶으면 가장 느린 것에 맞춰집니다.
   → 느린 조회는 분리해 카드 단위로 채웁니다.
